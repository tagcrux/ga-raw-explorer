Privacy Policy

Last updated: November 8, 2026

GA Raw Explorer ("the app") is an open-source web application operated by tagcrux. It lets you view raw Google Analytics 4 report data for the accounts and properties you already have access to. This policy explains what data the app accesses, how it is used and how it is protected.

Summary

  • The app runs entirely in your browser. It has no backend server and no database.
  • Your Google data is never sent to, stored on, or shared with any server operated by us or by third parties.
  • Access is read-only and lasts only until you sign out, close the tab, or the token expires (about one hour).

Data the app accesses

When you sign in with Google and grant permission, the app requests these OAuth scopes:

  • https://www.googleapis.com/auth/analytics.readonly: to list your Google Analytics accounts and properties (Google Analytics Admin API), load the dimensions and metrics available for a property, check their compatibility, and run the reports you request (Google Analytics Data API).
  • openid and email: to show the email address of the signed-in account in the app header.

The app cannot modify, delete or create anything in your Google Analytics accounts.

How the data is used

Data received from Google APIs is used only to display it to you in your browser: the list of accounts and properties, the available fields, and the report tables you request. It is not used for advertising, profiling, analytics, or training of any kind.

Data protection

We protect Google user data, including sensitive Google Analytics data, with the following measures:

  • Encryption in transit: the app is served only over HTTPS (HTTP is redirected to HTTPS), and all requests to Google APIs and Google Identity Services use HTTPS/TLS.
  • No server-side copy: the app has no backend, database or logging service. Google user data is never transmitted to, stored on, or accessible from any server operated by us, so there is no stored copy that could be breached or accessed by our staff.
  • In-memory token only: the OAuth access token is kept only in the browser's memory. It is not written to cookies, localStorage, sessionStorage, IndexedDB or any server.
  • Short-lived, least-privilege access: the app requests only the read-only scope analytics.readonly and uses Google's short-lived access tokens (about one hour), without refresh tokens or offline access.
  • Minimal third-party code: the only external script loaded is Google Identity Services (accounts.google.com). No analytics, advertising or tracking scripts are used.
  • Transparency: the full source code is public, so these measures can be independently verified.

Data retention and deletion

  • Retention: we do not retain any Google user data. Account lists, field metadata and report data exist only in the open browser tab while you use the app.
  • Automatic deletion: all Google user data is deleted from memory when you sign out, when you close or reload the tab, or when the access token expires (about one hour), whichever comes first. On expiry the app clears its state and asks you to sign in again.
  • Sign out: signing out revokes the access token with Google and immediately clears all data from the page.
  • Revoking access: you can also remove the app's access at any time from your Google Account at myaccount.google.com/permissions.
  • Exports: if you choose "Export CSV" or "Export JSON", the file is created locally in your browser and saved to your own device. It is never uploaded anywhere; you control and can delete it at any time.
  • Deletion requests: because we hold no Google user data on any server, there is nothing for us to delete. If you have questions, contact developer@tagcrux.com and we will respond within 30 days.

Sharing

We do not sell, transfer or share Google user data with anyone. Requests go directly from your browser to Google's APIs (googleapis.com) and to Google Identity Services (accounts.google.com) for sign-in.

Hosting, cookies and tracking

The app is a static website hosted on GitHub Pages. It does not use cookies, analytics, tracking pixels or advertising. GitHub, as the hosting provider, may process technical data such as IP addresses in its server logs; see the GitHub Privacy Statement. Google's own processing of your sign-in is governed by the Google Privacy Policy.

Google API Services User Data Policy

GA Raw Explorer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can sign out in the app at any time, which revokes the token. You can also remove the app's access from your Google Account at myaccount.google.com/permissions.

Children

The app is a professional analytics tool and is not directed at children under 13.

Open source

The complete source code is public at github.com/tagcrux/ga-raw-explorer, so every statement in this policy can be verified.
